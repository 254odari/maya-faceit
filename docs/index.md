# Maya FaceIT Documentation

**FaceIT** is a professional facial rigging and blendshape pipeline for Autodesk Maya.  
It provides a complete toolkit for creating, driving, optimizing, and exporting facial blendshapes, with native support for ARKit, mocap integration, and expression libraries.

## Features

- **Blendshape Creation** – Create targets from meshes, combine, mirror, normalize.
- **ARKit 52** – Full support for Apple’s ARKit blendshape set.
- **Mocap Live Drive** – Connect to LiveLink, MediaPipe, FaceCap, etc.
- **Expression Library** – Store, blend, and apply poses.
- **Optimization** – Reduce memory and performance footprint.
- **Validation & Diagnostics** – Catch issues before export.
- **Export** – FBX, USD, Alembic, MetaHuman, and custom formats.
